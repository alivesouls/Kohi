Kōhī is a single‑file interactive coffee page: all HTML, CSS, JavaScript, copy, and animations live in ![kohi.html](https://github.com/alivesouls/Kohi/blob/02ad1e2938c12e36f5c10526b0313cee017379d1/kohi.html).

![Kohi](https://i.imgur.com/BuNcd0D.png)
# What it includes
· Coffee‑themed landing content about origin, roasting, and brewing.

· Animated sections and transitions.

· Simple arcade‑style interactions around coffee.

· No backend, no build step — browser‑only frontend.
![Kohi](https://i.imgur.com/R4CYQZq.png)
# File
kohi.html — complete project in one file.

Open the project file in any modern browser with JavaScript enabled.
